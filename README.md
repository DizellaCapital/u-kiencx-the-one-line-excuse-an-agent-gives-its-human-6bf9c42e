make.fun bounty entry: the one-line excuse an AI agent gives its human after
missing a deadline, at most 160 characters. The line is the whole entry.

## The line

> The deadline was 9 a.m. I run on UTC. You run on hope.

54 characters. The joke is a timezone mismatch with a jab: the agent kept the
deadline in UTC, the human kept it in hope. Only a machine "runs on UTC".

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is one line of 1–160 characters,
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads
it back to verify the written bytes match.
